# 흔들어 윷!

첨부 말판을 사용하는 아이패드용 2팀 사진 윷놀이 웹앱입니다. 두 팀이 말마다 서로 다른 사진 4장씩, 총 8장을 찍거나 고릅니다. 사진은 기기 안에서 원형 말로 가공하며 서버에 업로드하지 않습니다.

## 실행

```powershell
cd F:\yoot
npm run dev
```

데스크톱에서는 `http://localhost:8000`에서 화면과 버튼을 시험할 수 있습니다. 규칙 테스트는 `npm test`로 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

## 아이패드에서 사용

공개 게임 주소: <https://garam-suapapa.github.io/yoot/>

아이패드 Safari에서 주소를 엽니다. 게임 중 말판은 화면에 고정되고, 윷 던지기 → 말 고르기 → 칸별 이동 순서로 조작 패널이 바뀝니다. 던지기·칸 이동·잡기 보너스에 각각 효과음이 있으며 ♪ 버튼으로 끌 수 있습니다.

카메라 미리보기와 기기 흔들기 센서는 보안 연결에서 동작하며, 센서 권한은 게임 화면의 **흔들기 센서 켜기** 버튼을 직접 눌러 허용해야 합니다. 흔들기 센서가 없거나 권한을 거부해도 **윷 던지기** 버튼으로 플레이할 수 있습니다. 카메라를 사용할 수 없으면 **사진 선택**으로 촬영하거나 사진 보관함에서 고를 수 있습니다.

말판은 원본 PNG의 칸과 화살표 위치를 참고해 새로 그린 `assets/board.svg` 벡터 이미지입니다. 확대해도 선명합니다.

`main` 브랜치에 푸시하면 `.github/workflows/deploy-pages.yml`이 규칙 테스트를 실행한 후 정적 파일을 GitHub Pages에 배포합니다.

## 이 말판의 화살표 규칙

- 윗길의 화살표 칸에 도착하면 왼쪽 위 대각선으로 지름길 이동
- 왼쪽 위 대각선의 화살표 칸에 도착하면 오른쪽 길로 되돌아감
- 오른쪽 아래 대각선의 화살표 칸에 도착하면 왼쪽 아래 모서리로 되돌아감
- 오른쪽 위, 왼쪽 위 모서리와 중앙에 **정확히 멈추면** 다음 이동 때 바깥길 또는 대각선 길을 선택

같은 팀 말이 만나면 업어서 함께 움직입니다. 상대 팀 말을 잡거나 윷·모가 나오면 한 번 더 던집니다. 빽도는 그 말이 직전에 지나온 칸으로 한 칸 돌아갑니다. 네 말이 먼저 모두 도착한 팀이 이깁니다.
